# settings/theme 概要

## 目的・背景

現在、UI の色は `src/styles/nord.css` に固定されており、利用者が変更する手段が無い。
2026-08-21 に「背景や見出しの色を設定で変えられるようにしたい」という要望を受けた。

長時間エディタを見続ける道具なので、配色の好みは個人差が大きい。とくに次の 2 つは
利用者ごとに要求が食い違う。

- **背景の明るさ** — 暗い部屋ではダークが楽だが、明るい環境ではライトの方が見やすい
- **見出しの色** — 現在は H1〜H6 が黄・緑・紫・水・青・青と派手に散っている。
  これは Nord の全色を使って階層を示す設計だが、落ち着いた単色を好む人もいる

さらに、**見出しの色は今のエイリアス層からは変更できない**という構造的な問題がある。
H1 は `--warning`、H2 は `--success`、H4 は `--accent` を参照しており、H4 を変えると
カーソル・リンク・リストの弾丸まで一緒に変わってしまう。用途別エイリアスは
「同じ意味の色をまとめる」ためのもので、「同じ色を使っている箇所をまとめる」ためのもの
ではないため、利用者向けの調整口としてはそのまま使えない。

## スコープ

### 作るもの

- **配色プリセット** — 名前付きの配色セット。Nord（既定）に加えてライトテーマを用意し、
  設定で切り替える
- **項目ごとの色の上書き** — プリセットの上に、利用者が個別の色を指定できる。
  対象は基本 6 種・見出し 6 種・コード 6 種・その他 5 種の計 23 項目（spec.md の表）
- **設定モーダルの配色セクション** — カラーピッカーで選び、保存で即反映
- **初期値に戻す** — 項目ごと / 全体の両方
- **見出し・コード用の CSS 変数の新設** — `--heading1`〜`--heading6` などを
  `nord.css` に足し、`editor/theme.ts` の直接参照（`--nord15` `--nord7`）を解消する

### 作らないもの

- 配色セットのファイル入出力（テーマの配布・共有）
- ノートごと・保管庫ごとの配色（アプリ全体で 1 つ）
- フォント以外の寸法（余白・行間・角丸）の設定
- 自動のライト/ダーク切り替え（OS の設定に追従する仕組み）
- 色以外のシンタックスハイライト属性（太さ・斜体・サイズ）の設定

## 制約

- 色は `nord.css` を唯一の定義元とする方針（`project_overview.md` の「カラーパレット」）を
  崩さない。上書きは**実行時に `documentElement` の CSS 変数を設定する**形で行い、
  CSS ファイル側の既定値はそのまま残す。`settings/ui` のフォント設定と同じ手口
- `--comment` `--quote-text` `--quote-bg` は `color-mix()` で `--nord4` などから
  計算されている。上書きした色に追従させるには、混合元をエイリアスに張り替える必要がある
- 設定の保存は `settings.json` の部分更新（`save_editor_settings` と同じく、
  `lastVault` を巻き込まない別コマンドにする）
- ライトテーマは色を差し替えるだけでは成立しない。`editor/theme.ts` の
  `{ dark: true }` と、暗い背景を前提にした境界線・選択範囲の見え方を見直す必要がある

## 完了条件

- 設定モーダルでプリセットを切り替えると、UI 全体の配色が即座に変わる
- 23 項目それぞれを個別に変更でき、保存後・再起動後も維持される
- 「初期値に戻す」でプリセットの色に戻る
- H1〜H6 を個別の色にできる（他の要素を巻き込まない）
- 色を上書きしていない項目はプリセットの色のまま追従する
- `settings.json` に配色が壊れた値で入っていても、起動できる

## 画面イメージ

```
+--------------------------------------------------+
|  設定                                            |
+--------------------------------------------------+
|  フォントサイズ        [ 14 ]                    |
|  フォントファミリー    [ システムフォント  v ]   |
|                                                  |
|  配色プリセット        [ Nord（ダーク）    v ]   |
|                                       [初期値に戻す] |
|  v 基本                                          |
|      背景        [■] #2e3440    サイドバー [■] ...|
|      文字        [■] #d8dee9    強調文字   [■] ...|
|      罫線        [■] #4c566a    アクセント [■] ...|
|  > 見出し                                        |
|  > コード                                        |
|  > その他                                        |
|                                                  |
|                         [ キャンセル ] [ 保存 ]  |
+--------------------------------------------------+
```

見出し・コード・その他は折りたたみ。既定は「基本」だけを開いた状態にする
（23 項目を一度に見せるとモーダルが縦に溢れるため）。
