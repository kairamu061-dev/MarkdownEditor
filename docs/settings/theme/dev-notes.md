# settings/theme 開発メモ

## 実装上の判断

| 判断内容 | 理由 |
|----------|------|
| **これ以上サブ項目に分割しない**（spec.md 完了時に判定・2026-08-21） | 分割条件を 4 つとも満たさない。UI 面は `settings/ui` の既存モーダルの中の 1 セクションで独自の画面ではない。スキーマは 21 項目のカラーマップ 1 つで、パレット定義・適用・UI で共有する。パレット定義だけを切り出しても、適用先が無いと動作を確認できず単独でテストできない。並行作業の単位にもならない |
| 設定項目を 21 個にした（見出し 1〜6 を個別に） | 2026-08-21 にユーザーが「見出し 1〜6 を個別に」を選択。8 項目案（見出しは 1 色）も提示したうえでの選択 |
| プリセットの色も毎回 21 項目すべて明示的に設定する | `nord.css` の既定値に頼って「Nord のときは何も設定しない」とすると、ライト → Nord に戻すときに `removeProperty` の取りこぼしで一部だけライトの色が残る事故が起きやすい。常に全部書けばこの経路が消える |
| `colors` を Rust 側で enum にせず `BTreeMap<String, String>` にする | 項目を将来増減したとき、古い `settings.json` でデシリアライズが失敗すると `theme` 全体が既定に落ちて**利用者の配色が丸ごと消える**。未知キーを捨てる判断は TS 側に寄せる。`BTreeMap` はキー順が安定するので保存のたびに差分が出ない |
| 引用の設定項目を 1 つ（バー色）にし、本文色と背景を導出する | 引用は左バー・本文・背景の 3 色で「引用らしさ」を出しているが、3 項目に増やすと設定画面が長くなるうえ、3 色の関係を利用者が壊せてしまう |
| コードの設定項目を 5 種に絞る | 関数名・演算子・変数名まで出すと 25 項目を超える。この 3 つはアクセント・文字色に従わせても実用上困らない |
| ライト/ダークの切り替えを `EditorView.darkTheme` ファセット + `Compartment` で行う | `EditorView.theme(spec, { dark })` の `dark` はこのファセットを立てているだけなので、ファセットだけ差し替えればテーマ定義を作り直さずに済む。テーマ本体は CSS 変数を参照しているため、色は変数の更新だけで追従する |
| `subscribeDark` は登録時に現在値で 1 回呼ぶ | `initSettings()` が `mountEditor()` より先に走るため、単純なイベント通知だと起動直後の 1 回を取りこぼす。順序依存を仕様で消す |

## 発生した問題と対処

| 問題 | 対処 |
|------|------|
| 見出しの色が用途別エイリアスを共有していて単独で変えられない（H1=`--warning`、H4=`--accent` など）。H4 を変えるとカーソル・リンク・リストの弾丸まで変わる | `--heading1`〜`--heading6` を新設し、既定値を現在の色と同じにする。用途別エイリアスは「同じ意味の色をまとめる」ためのもので、「利用者の調整口」としては粒度が合っていなかった |
| `--comment` / `--quote-text` / `--quote-bg` が `color-mix()` で `--nord4` `--nord3` `--nord9` から計算されており、エイリアスを上書きしても追従しない | `--comment` は `--code-comment` に統合して混合をやめる。引用の 2 つは混合元を `--text` / `--border` / `--quote-bar` に張り替える |
| `--nordN` を直接参照している箇所が 4 つあり、上書きしてもそこだけ Nord のまま残る（`editor/theme.ts` に 3 つ、`app.css` に 1 つ） | 新変数・エイリアスへ差し替える。`grep -rn "var(--nord" src/ \| grep -v styles/nord.css` が空になることを検査項目にした |

## 今後の課題

- **ライトテーマは色の差し替えだけでは完成しない。** 暗い背景を前提にした境界線の濃さ、
  選択範囲の見え方、スクロールバー、コードブロックの背景が、明るい下地では
  コントラストが足りない可能性がある。実装時に目視で詰める
- **コントラスト比の検証は行わない。** 背景と文字を同じ色にすることも止めない。
  「すべて初期値に戻す」で復旧できることを逃げ道にしている。設定画面の外
  （たとえばコマンドパレット）から復旧する手段は用意していない
- 配色セットのファイル入出力（テーマの配布）は未対応。要望があれば
  `ThemeSettings` をそのまま JSON に書き出す形で足せる
