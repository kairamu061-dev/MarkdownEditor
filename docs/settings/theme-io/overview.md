# settings/theme-io 概要

## 目的・背景

`settings/theme` で配色を自由に変えられるようにしたが、**作った配色はそのアプリの中に
閉じている**。他の環境に持っていくことも、誰かが作った配色を取り込むこともできない。

2026-08-23 に「配色をエクスポート／別のテーマとしてインポートしたい」という要望を受けた。
`settings/theme` の overview では「配色セットのファイル入出力」を作らないものに挙げていたが、
その判断を取り消す。

利用者が求めているのは 2 つ。

- **持ち出し** — 今の配色（プリセット + 項目ごとの上書き）を 1 つのファイルに書き出す
- **持ち込み** — ファイルを読み込み、**名前付きのテーマとしてプリセットの一覧に加える**。
  以後はいつでも切り替えられ、不要になったら削除できる

「その場で適用するだけ」ではなく**一覧に加わる**形にすることは、2026-08-23 に
利用者が選択した。複数のテーマを行き来できることが要件。

## スコープ

### 作るもの

- **エクスポート** — 今画面に見えている配色を、名前付きの JSON ファイルとして保存する
- **インポート** — JSON ファイルを読み、利用者テーマとして `settings.json` に登録する
- **利用者テーマの一覧** — 組み込みプリセット（Nord / ライト）と並んで選択欄に出る
- **削除** — 選択中の利用者テーマを一覧から消す
- **テーマファイルの形式** — 他の環境でもそのまま読める、自己完結した形式

### 作らないもの

- テーマの配布サイト・オンライン取得（ローカルのファイル入出力のみ）
- 組み込みプリセット（Nord / ライト）の書き換え・削除
- 利用者テーマの**名前の変更**（作り直せば済む）
- テーマファイルの**自動再読み込み**（元ファイルを編集しても取り込み済みの内容は変わらない）
- 配色以外（フォント・寸法・キーバインド）の入出力
- フォルダを指定して複数テーマを一括取り込みすること

## 制約

- **テーマファイルは自己完結でなければならない。** 「Nord からの差分」では、
  受け取った側の Nord が将来変わったときに意味が変わる。23 項目すべてを書き出す
- **明暗（`dark`）を持たせる必要がある。** CodeMirror の基底テーマの明暗は
  `EditorView.darkTheme` で切り替えており、組み込みプリセットは `Preset.dark` を持っている。
  利用者テーマにこれが無いと、ライト系のテーマを取り込んでもエディタの既定スタイルが
  暗いままになる
- 保存先は `settings.json`（`settings/store` の部分更新コマンド経由）。
  ファイルダイアログは `tauri-plugin-dialog`（保管庫を開くのと同じ仕組み・導入済み）
- **組み込みプリセットの名前と衝突させない。** 現在 `preset` は `"nord" | "light"` の
  文字列で、未知の値は Nord に落ちる。利用者テーマは別の名前空間に置く

## 完了条件

- 今の配色をファイルに書き出し、**別の環境で読み込んで同じ見た目になる**
- 取り込んだテーマがプリセットの選択欄に名前付きで並び、切り替えられる
- 取り込んだテーマが再起動後も残る
- 取り込んだテーマを削除でき、削除しても他の設定が壊れない
- 壊れたファイル・配色ではないファイルを読ませても、アプリが壊れず理由が分かる

## 画面イメージ

```
+--------------------------------------------------+
|  設定                                            |
+--------------------------------------------------+
|  ...フォント...                                  |
|                                                  |
|  配色                                            |
|  配色プリセット   [ Nord（ダーク）          v ]  |
|                     ├ Nord（ダーク）             |
|                     ├ ライト                     |
|                     ├ Solarized       ← 取り込み |
|                     └ 自作テーマ      ← 取り込み |
|                                                  |
|  [エクスポート] [インポート] [このテーマを削除]  |
|                       ↑ 利用者テーマ選択時のみ   |
|  [すべて初期値に戻す]                            |
|  v 基本 / > 見出し / > コード / > その他         |
+--------------------------------------------------+
```

「このテーマを削除」は、**利用者テーマを選んでいるときだけ**表示する
（組み込みプリセットは削除できない）。
