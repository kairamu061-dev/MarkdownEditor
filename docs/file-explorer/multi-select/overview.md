# file-explorer/multi-select 概要

## 目的・背景

フォルダビューでは、ノートをフォルダへ移すには 1 件ずつドラッグするしかない。
整理のために多数のノートをまとめて移したいとの要望（2026-10-23）を受け、
Windows のエクスプローラーと同じように **マウスで四角を描いて複数のノートを選び、
そのうち 1 件をドラッグすれば選択中のノートがまとめて移動する** ようにする。

## スコープ

### 作るもの

- 範囲選択（マーキー）: 行の名前より右の空白や、ツリー下の余白からドラッグして四角を描き、
  四角に掛かったノートを選択する
- 選択状態の表示（行のハイライト）と解除（クリック・Esc・保管庫の切り替え）
- Ctrl + 範囲選択で選択に追加、Ctrl + クリックで 1 件ずつ選択を切り替え
- 選択中のノートのどれかをドラッグすると、選択中のノートすべてを同じフォルダへ移動する

### 作らないもの

- フォルダの複数選択（選択できるのはノートだけ）
- Shift + クリックによる連続範囲の選択、キーボードによる選択
- 選択中のノートへの一括操作（削除・リネームなど）。右クリックメニューは従来どおり 1 件が対象

## 制約

- 行の名前の上からのドラッグは、従来どおり 1 件の移動（tree-view のドラッグ&ドロップ移動）。
  範囲選択はそれ以外の場所から始める（ユーザーの選択: エクスプローラー式）
- 移動はバックエンドの既存コマンド `move_path` を 1 件ずつ呼ぶ。Rust 側は変更しない
- 選択色は新しいテーマ変数を足さず、既存の `--accent` から作る（theme-io の書き出し項目を増やさない）

## 完了条件

- ツリーの空白部からドラッグで四角を描くと、掛かったノートが選択表示になる
- 選択中のノートの 1 件をフォルダへドラッグすると、選択中のノートがすべてそのフォルダへ移る
- 一部が移動できなかった場合（同名の項目がある等）は件数をステータスに出し、残りは移動する
- 名前の上からのドラッグ・クリックでノートを開く・フォルダの開閉は従来どおり動く

## 画面イメージ

```
+---------------------------+
| ▾ 仕事                    |
|   議事録      ┌───────┐   |
|  [メモA      ]│       │   |  ← 選択中（ハイライト）
|  [メモB      ]│ 範囲  │   |
|   メモC      └───────┘   |
|                           |  ← ツリー下の余白からも描ける
+---------------------------+
```
