# file-explorer/multi-select 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | 範囲選択 | ツリーの「名前以外の場所」から左ボタンでドラッグすると四角（マーキー）を描き、四角に掛かったノート行を選択する。描いている間、選択は随時更新される |
| 2 | 追加選択 | Ctrl を押しながら範囲選択すると、既存の選択に追加する。Ctrl + クリック（ノート行）で、そのノートの選択を切り替える（ノートは開かない） |
| 3 | 選択の表示 | 選択中のノート行を `--accent` 由来の色でハイライトする。開いているノートの強調（`active`）とは別の見た目 |
| 4 | 選択の解除 | 修飾キーなしでノートをクリック（開く）・空白部をクリック・Esc・保管庫の切り替えで全解除 |
| 5 | まとめて移動 | 選択中のノートのどれかをドラッグすると、選択中のノートすべてを移動対象にする。ドラッグ中の表示に件数を出す |
| 6 | 選択の保持 | ツリーの再描画・移動・リネームをまたいで選択を保つ（移動・リネームしたノートは新しいパスで選択されたまま）。削除したノートは選択から外す |

## 画面・操作フロー

1. ノートの名前より右の空白、またはツリー下の余白で左ボタンを押す
2. 4px 以上動かすと範囲選択が始まり、押した点からポインタまでの四角が表示される
3. 四角に掛かったノート行が選択表示になる（フォルダ行・折りたたまれて見えない行は対象外）
4. ボタンを離すと四角が消え、選択が確定する
5. 選択中のノートの **名前** をつかんでフォルダ行（またはツリー空白部 = ルート）へドラッグする
6. ドロップすると、選択中のノートがすべてそのフォルダへ移り、ツリーが更新される

## 各画面 / 状態の詳細

### 範囲選択の開始位置

- **名前の上**（`.tree-label`・開閉マーク）: 従来どおり。クリック = 開く / 開閉、ドラッグ = その項目の移動
- **それ以外**（行の名前より右・ツリー下の余白・インデントの左側）: ドラッグ = 範囲選択。
  4px 未満でボタンを離した場合はただのクリックとして扱い、行の上なら従来どおり開く / 開閉、
  行の外なら選択を全解除する
- 範囲選択を終えたあとのクリックは発火させない（離した位置のノートが開いたりフォルダが開閉したりしない）

### 範囲選択中

- **表示内容**: 半透明の四角（枠線 `--accent`）。四角に掛かったノート行は随時選択表示
- **操作**: ポインタをサイドバーの上端・下端付近へ寄せるとツリーがスクロールし、四角も追従する
- **確定**: ボタンを離すと四角が消える。Ctrl なしで始めた場合、開始時点で既存の選択は破棄されている

### ドラッグ移動（選択あり）

- 選択中のノートをドラッグした場合: 移動対象 = 選択中のノートすべて
- 選択されていないノート・フォルダをドラッグした場合: 移動対象 = その 1 件（従来どおり）。選択は変えない
- ドロップ先の可否: 移動対象のうち **1 件でも** そのフォルダへ移せるならドロップを受け付ける。
  すでにそのフォルダにあるノートは飛ばす（エラーにしない）
- 移動前に、編集中ノートの保存待ちを確定する（移動中に古いパスへ書き込まないため）
- 移動後は、移したノートが新しいパスで選択されたまま残る

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 移動先に同名の項目がある（1 件の移動） | 従来どおりステータス「移動先に同名の項目があります」 |
| 複数件のうち一部が同名で移動できない | 移せるものは移し、ステータス「同名の項目があるため N 件は移動しませんでした」 |
| 複数件のうち一部がその他の理由で失敗 | 移せるものは移し、ステータス「N 件の移動に失敗しました」 |

## 未対応ケース

- フォルダの複数選択（範囲に掛かってもフォルダ行は選択しない）
- Shift + クリックの連続選択、Ctrl + A、キーボード操作
- 選択中のノートの一括削除・一括リネーム（右クリックメニューは押した 1 件が対象）
- 移動の取り消し（Undo）
