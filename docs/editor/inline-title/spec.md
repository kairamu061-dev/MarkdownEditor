# editor/inline-title 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | ノート名の表示 | エディタ領域の最上部に、開いているノートのベース名（`.md` を除く）を表示する |
| 2 | 表示の追随 | ノート切替・リネーム・ドラッグ移動・保管庫切替で表示を更新する |
| 3 | インラインリネーム | タイトル行をクリックして編集し、Enter / フォーカスアウトで確定してファイルをリネームする |
| 4 | 未保存状態の表示 | ノートを開いていない（スクラッチ文書）ときは「無題」を編集不可で表示する |
| 5 | 入力検証とエラー通知 | 空文字・パス区切り文字・同名衝突を弾き、ステータスで通知する |

## 画面・操作フロー

### ノート名の確認

1. ツリーでノートをクリックして開く
2. エディタ最上部のタイトル行にノート名が表示される
3. サイドバーを閉じても（Ctrl+B）タイトル行は残るため、何を編集中か分かる

### タイトルからのリネーム

1. タイトル行をクリックする
2. 入力欄に切り替わり、既存の名前が全選択された状態になる
3. 新しい名前を入力する
4. Enter を押す（またはタイトル行の外をクリックする）
5. ファイルがリネームされ、ツリーの表示・強調が追随する
6. タイトル行は表示状態に戻り、フォーカスはエディタ本文へ移る

途中で Escape を押すと、変更を破棄して表示状態に戻る。

## 各画面 / 状態の詳細

### 表示状態（ノートを開いている）

- **表示内容**: ノートのベース名（例: `sub/買い物リスト.md` → `買い物リスト`）
- **操作**: クリックで編集状態へ
- **遷移先**: 編集状態

### 表示状態（スクラッチ文書 / `currentPath === null`）

- **表示内容**: `無題`（本文と区別できるよう淡色で表示）
- **操作**: クリックしても反応しない
- **遷移先**: なし。ノートを開くと通常の表示状態になる

### 編集状態

- **表示内容**: 現在の名前が入った入力欄（初期状態で全選択）
- **操作**:
  - `Enter` — 確定
  - `Escape` — 破棄して表示状態へ
  - フォーカスアウト — **妥当かつ変更ありなら確定**、それ以外は破棄（BUG-016 と同じ方針）
  - その他のキー入力はエディタへ伝播させない（`stopPropagation`）
- **遷移先**: 表示状態

### 確定時の処理順序

1. `flushSave()` — 保留中の自動保存を確定させる（**リネームより先**。順序が逆だと旧パスへ保存が飛ぶ）
2. 入力値の検証（下記エラーケース）
3. `renamePath(from, to)`
4. `remapAfterRename(from, to)` — 開いているノートのパス・ツリーの折りたたみ状態を追随（BUG-013 の対処を再利用）
5. `refreshTree()`
6. 表示状態へ戻し、エディタ本文へフォーカスを返す

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 名前が空（空白のみを含む） | 確定しない。編集状態のまま留まる |
| 名前に `/` または `\` を含む | 確定しない。編集状態のまま留まる（フォルダ移動は D&D の役割） |
| 名前が変更されていない | リネームを実行せず、そのまま表示状態へ戻る |
| 同名のノートが既に存在する | `同名の項目があります` をステータス表示。入力を残して再試行できる |
| リネームがその他の理由で失敗 | `操作に失敗しました` をステータス表示し、表示状態へ戻す。コンソールに詳細を出す |
| リネーム前の `flushSave()` が失敗 | 既存の保存失敗時の挙動に従う。リネームは実行しない（保存できていない内容を旧パスに残さないため） |

## 未対応ケース

- 本文先頭の H1 見出しとの連動（双方向同期）
- スクラッチ文書へのタイトル入力による新規ノート作成
- 拡張子の変更（`.md` は固定。入力欄では拡張子を扱わない）
- タイトル行からのフォルダ移動（パス区切り文字の入力は拒否する）
- リネームに伴う被リンクの自動書き換え（`[[旧名]]` は旧名のまま残る）
- 複数ノートのタブ表示・パンくず（親フォルダ）の表示
