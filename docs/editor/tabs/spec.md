# editor/tabs 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | タブバー | エディタ領域の最上部（inline-title の上）に、開いているノートをタブで並べる。ラベルはベース名（`.md` を除く）、ツールチップは保管庫相対パス |
| 2 | アクティブなタブで開く | ツリーの通常クリック・ウィキリンク・相対パスのリンク・新規ノート作成は、アクティブなタブの中身をそのノートに置き換える。タブが 1 つも無ければ新しく作る |
| 3 | 新しいタブで開く | ツリーのノート行の中クリック、または右クリックメニュー「新しいタブで開く」で、アクティブなタブの右に新しいタブを作って開く |
| 4 | 重複の防止 | すでにいずれかのタブで開いているノートを開こうとしたら、新しく開かず、そのタブへ切り替える（2〜3 のすべてに適用） |
| 5 | タブの切り替え | タブのクリック、Ctrl+Tab（右へ）/ Ctrl+Shift+Tab（左へ）。端では反対側へ回り込む |
| 6 | 編集状態の保持 | タブごとに undo 履歴・カーソル/選択・スクロール位置を保ち、切り替えて戻ると元の状態で再開する |
| 7 | タブを閉じる | × ボタン、タブの中クリック、Ctrl+W（アクティブなタブ）。最後の 1 つを閉じるとスクラッチ文書（何も開いていない状態）に戻る |
| 8 | 追随 | リネーム・移動でラベルとパスを全タブで更新する。削除したノート（フォルダならその配下）のタブは閉じる。保管庫を切り替えたら全タブを閉じる |

## 画面・操作フロー

### 複数のノートを並べて開く

1. ツリーでノート A をクリックする → タブ [A] が作られ、A が開く
2. ノート B を中クリックする → [A] の右に [B] が作られ、B がアクティブになる
3. ノート C を通常クリックする → アクティブな [B] の中身が C に置き換わる（[A] [C]）
4. タブ [A] をクリックする → A が、離れたときのカーソル位置・スクロール位置・undo 履歴のまま表示される

### 閉じる

1. アクティブなタブの × を押す（または Ctrl+W）
2. 右隣のタブがアクティブになる。右隣が無ければ左隣
3. 最後のタブを閉じると、エディタは空のスクラッチ文書になり、inline-title は「無題」表示になる

## 各画面 / 状態の詳細

### タブバー

- **表示内容**: 開いている順（新しいタブはアクティブなタブの右に入る）にタブを並べる。
  アクティブなタブは背景色と上辺のアクセント色で区別する
- **幅**: 各タブは名前の幅（最大幅を超える分は末尾 … で切り詰め）。並びきらないときもタブは縮めず、タブバーを横スクロールし（スクロールバーは細く、他の領域と同じ配色）、
  アクティブなタブが見える位置までスクロールする
- **タブが 0 個**: タブバー自体は高さを保ったまま空で表示する（レイアウトが上下に跳ねないため）
- **ツリーの強調**: ツリーの `active` 強調はアクティブなタブのノートだけに付く（従来どおり 1 件）

### タブ上の操作

| 操作 | 結果 |
|------|------|
| クリック | そのタブへ切り替える |
| 中クリック | そのタブを閉じる（アクティブでなくても閉じられる） |
| × ボタン | そのタブを閉じる。× のクリックは切り替えを伴わない |

### キー操作

| キー | 結果 |
|------|------|
| Ctrl+Tab | 右のタブへ（右端なら左端へ） |
| Ctrl+Shift+Tab | 左のタブへ（左端なら右端へ） |
| Ctrl+W | アクティブなタブを閉じる。タブが無ければ何もしない |

エディタ本文・ツリーなど、どこにフォーカスがあっても効く。
ただし、名前の入力欄（inline-title / ツリーのリネーム）で編集している間は効かない（閉じると入力が黙って捨てられるため）。

### ツリーとの関係

| ツリーでの操作 | 結果 |
|---------------|------|
| ノート行のクリック | アクティブなタブで開く（重複時はそのタブへ切り替え） |
| ノート行の中クリック | 新しいタブで開く（重複時はそのタブへ切り替え） |
| ノート行の右クリック → 「新しいタブで開く」 | 中クリックと同じ。フォルダ行・空白部（ルート）には出さない |
| ノート行の Ctrl+クリック | 従来どおり選択の切り替え（multi-select）。開かない |
| フォルダ行の中クリック | 何もしない |

### 保存とタブの切り替え

- 切り替え・閉じる・保管庫の切り替えの前に、アクティブなタブの保存待ち（debounce 中の内容）を必ず確定する
- そのため、保存待ちの内容を持つのは常にアクティブなタブだけになる。ウィンドウを閉じるときの保存（BUG-017）は従来どおりアクティブなタブだけを対象にすればよい

### 追随

| 出来事 | 結果 |
|--------|------|
| ノートのリネーム（ツリー / inline-title） | そのノートのタブのラベルとパスを更新する |
| フォルダのリネーム・移動 | 配下のノートのタブすべてのパスを更新する（ラベルはベース名なので変わらない） |
| ノートの削除 | そのノートのタブを閉じる。アクティブだった場合は「閉じる」と同じ規則で隣へ移る |
| フォルダの削除 | 配下のノートのタブをすべて閉じる |
| 保管庫の切り替え | 全タブを閉じ、スクラッチ文書に戻る |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 切り替え前の保存に失敗した | ステータス「保存できていないため切り替えられません」。切り替えず、アクティブなタブに留まる |
| 閉じる前の保存に失敗した | ステータス「保存できていないため閉じられません」。タブは閉じない |
| 保管庫切り替え前の保存に失敗した | ステータス「保存できていないため保管庫を切り替えられません」。切り替えない |
| 開くノートの読み込みに失敗した | 従来どおりステータス「読み込みに失敗しました」。タブの並び・アクティブなタブは変えない |

保存に失敗した内容は、アクティブなタブのエディタにそのまま残る。次に本文を変更すると、全文の保存が再試行される（従来の BUG-014 の扱いと同じ）。

書き込みが失敗し続ける（読み取り専用・他のアプリがロックしている等）と、そのタブから離れられない。
抜け道は、原因を取り除いてから本文を 1 文字変える（再保存させる）か、そのノートをツリーから削除するか、アプリを再起動する（未保存分は失われる）。

スクラッチ文書（タブ 0 個）は保存しないため、常に「確定済み」として扱う。スクラッチ上で Ctrl+S を押しても、以後の操作は止まらない。

## 未対応ケース

- 再起動時のタブの復元
- 空のタブ・Ctrl+T
- 同じノートを複数のタブで開くこと
- タブのドラッグ並べ替え・ピン留め・分割表示・タブの右クリックメニュー
- Ctrl+クリック（ツリー・リンク）で新しいタブを開くこと
- ウィキリンク / 相対リンクから新しいタブで開くこと（常にアクティブなタブで開く）
- アプリの外でファイルが変更されたときの反映（裏のタブは開いた時点の内容を保持する。従来も外部変更は検知していない）
