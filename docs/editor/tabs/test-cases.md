# editor/tabs テストケース

自動テストの仕組みが無いため、Windows のビルドでの手動確認（E2E）だけを置く。

## E2Eテスト

| ID | テスト名 | 前提条件 | 手順 | 期待結果 | ステータス |
|----|---------|---------|------|---------|-----------|
| E-01 | 通常クリックで開く | タブなし | ノート A をクリック | タブ [A] ができ、A が開く。ツリーの A が強調される | [x] |
| E-02 | 置き換え | [A] がアクティブ | ノート B をクリック | タブは 1 つのまま [B] になる | [x] |
| E-03 | 中クリックで新しいタブ | [A] がアクティブ | ノート B を中クリック | [A] の右に [B] ができてアクティブになる。自動スクロールのアイコンが出ない | [x] |
| E-04 | メニューから新しいタブ | [A] がアクティブ | B を右クリック →「新しいタブで開く」 | E-03 と同じ。フォルダ・空白部のメニューには項目が出ない | [x] |
| E-05 | 重複の防止 | [A] [B]、B がアクティブ | ツリーで A をクリック / 中クリック | どちらもタブは増えず [A] へ切り替わる | [x] |
| E-06 | 状態の保持 | [A] [B] | A でスクロール・カーソル移動・文字入力 → [B] → [A] | A のスクロール位置・カーソル位置が戻り、Ctrl+Z で直前の入力が取り消せる | [x] |
| E-07 | 切り替え直前の保存 | [A] [B] | A に文字を入力して 700ms 以内に [B] をクリック → アプリを再起動して A・B を開く | 入力は A にだけ保存され、B は変わっていない | [x] |
| E-08 | キー操作 | [A] [B] [C]、A がアクティブ | Ctrl+Shift+Tab → Ctrl+Tab ×2 → Ctrl+W | C → A → B と移り、B が閉じて C がアクティブになる | [x] |
| E-09 | フォーカスの位置 | [A] [B] | ツリーのノートをクリックしてから Ctrl+Tab / inline-title をクリックして編集中に Ctrl+W | 前者はタブが切り替わる。後者は何も起きず、入力中の名前が残る | [x] |
| E-10 | 閉じる | [A] [B] [C]、B がアクティブ | B の × → A を中クリック → C の × | B を閉じると C がアクティブ、A を閉じても C のまま、最後に「無題」の空文書 | [x] |
| E-11 | リネームの追随 | [A] [B]、A がアクティブ | ツリーで B をリネーム / inline-title で A をリネーム | 両方のタブのラベルが新しい名前になる。B に切り替えて編集すると新しいファイルに保存される | [x] |
| E-12 | フォルダ移動の追随 | フォルダ F 配下のノート X を裏のタブで開いている | F を別フォルダへドラッグ → X のタブへ切り替えて編集 | 移動後のパスへ保存される（ツールチップも新しいパス） | [x] |
| E-13 | 削除の追随 | [A] [B]（B は裏） | ツリーで B を削除 | タブ [B] が閉じる。A はそのまま | [x] |
| E-14 | フォルダ削除の追随 | F 配下の X・Y を開き、X がアクティブ | F を削除 | X・Y のタブが閉じる。他のタブがあればそちら、無ければ「無題」 | [x] |
| E-15 | 保管庫の切り替え | タブ複数 | 別の保管庫に切り替える | 全タブが閉じて「無題」になる | [x] |
| E-16 | 配色の追随 | [A] [B] | B を開いたまま設定でライト/ダークを切り替え → [A] | A も新しい配色で表示される | [x] |
| E-17 | ウィキリンク | [A] [B]、A がアクティブ、A に `[[B]]` | リンクをクリック | タブは増えず [B] へ切り替わる | [x] |
| E-19 | スクラッチでの Ctrl+S | タブ 0 個（起動直後 or 全タブを閉じた後） | Ctrl+S → ツリーのノートをクリック | ノートが開く（「保存できていないため〜」で止まらない） | [x] |
| E-18 | タブの多さ | 10 個以上開く | タブバーを見る | 横スクロールでき、アクティブなタブが見える位置にある | [x] |

2026-11-23 Windows 11 実機（WebView2・`dab6f1a`）で全件合格。E-06 のスクロール位置のずれ（最大 28px）は BUG-038、
E-18 の横スクロールバーの見た目は BUG-039、タブが多いときのラベルの読みにくさは BUG-040 として修正済み（`fe7f76b`、未検証）。

## ステータス凡例

- `[ ]` 未実施
- `[~]` 実施中
- `[x]` 合格
- `[!]` 不合格
