# editor/tabs 概要

## 目的・背景

今はノートを 1 つしか開けず、別のノートを参照するたびにツリーから開き直す必要がある。
開き直すと undo 履歴・カーソル位置・スクロール位置が失われる。
Obsidian と同じく、エディタ上部のタブで複数のノートを開いておき、行き来できるようにする。

## スコープ

### 作るもの

- エディタ領域の上部に置くタブバー（ノート名・閉じるボタン・アクティブ表示）
- タブごとの編集状態の保持（undo 履歴・カーソル/選択・スクロール位置）
- タブの切り替え（クリック・Ctrl+Tab / Ctrl+Shift+Tab）と閉じる操作（× ボタン・中クリック・Ctrl+W）
- ツリーからの開き方の使い分け（Obsidian 準拠）
  - 通常クリック: アクティブなタブで開く
  - 中クリック・右クリックメニュー「新しいタブで開く」: 新しいタブで開く
- リネーム・移動・削除・保管庫切り替えへのタブの追随

### 作らないもの

- 再起動時のタブの復元
- 空のタブ（Obsidian の「新しいタブ」画面）と Ctrl+T
- 同じノートを複数のタブで開くこと（開いていればそのタブへ切り替える）
- タブのドラッグによる並べ替え・ピン留め・分割表示
- Ctrl+クリックで新しいタブを開く操作（ツリーの Ctrl+クリックは multi-select の選択切り替えに使用済み）

## 制約

- エディタ（CodeMirror の `EditorView`）は 1 つのまま使い回す。タブの数だけビューを作らない（軽さ優先・project_overview.md）
- editor 配下は保管庫を知らない（editor/design.md の横断事項）。タブはノートのパスを不透明なキーとして扱う
- 自動保存（700ms debounce）は従来どおり。保存待ちの内容を持てるのはアクティブなタブだけとする
- 色は `nord.css` のエイリアスを参照する

## 完了条件

- 複数のノートをタブで開き、切り替えても各タブの undo 履歴・カーソル・スクロール位置が保たれる
- 切り替え直前の編集が、切り替え前のノートに正しく保存される（別のノートへ書き込まれない）
- リネーム・移動でタブのノート名が追随し、削除・保管庫切り替えで該当タブが閉じる
- spec.md のエラーケースと test-cases.md のケースを Windows のビルドで確認済み

```
|                |                                                |
|                | 本文 ...                                        |
+----------------+------------------------------------------------+
```
