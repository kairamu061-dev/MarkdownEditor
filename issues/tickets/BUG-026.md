# BUG-026: 番号付きリストで Tab が入れ子にならず、番号も振り直されない

- **State**: Closed
- **Reported**: 2026-08-20
- **Area**: editor/live-preview（@codemirror/commands の `indentMore`）

## Summary

番号付きリストの項目で Tab を押しても入れ子にならず、番号も変わらない。
見た目上は 2 スペースぶん字下げされるので「インデントは変わったのに番号が変わらない」
ように見える。

## Reproduction

1. 次の内容を入力する

```
1. a
2. b
3. c
```

2. 2 行目にカーソルを置いて Tab

観察（ディスク実内容）:
```
1. a
  2. b        ← 2 スペースだけ。入れ子になっていない。番号も 2 のまま
3. c          ← 3 のまま
```

## Expected

```
1. a
   1. b       ← 入れ子になり、入れ子リストの先頭なので 1
2. c          ← 繰り上がる
```

## Cause

`indentWithTab` が呼ぶ `indentMore` は `indentUnit`（既定 2 スペース）を足すだけ。

CommonMark で入れ子になる条件は「親項目の**本文が始まる桁**まで字下げされていること」。

- 箇条書きの `- ` はマークが 2 文字 → 2 スペースで条件を満たすので**たまたま**入れ子になる
- 番号付きの `1. ` は 3 文字 → **2 スペースでは足りず**、入れ子にならない

入れ子にならない＝構造が変わらないので、リストは 3 項目のままであり、番号 `2.` `3.` は
そのリストの中では正しい。つまり「番号が振り直されない」のではなく、
**そもそも段が変わっていなかった**。

番号付きリストの採番機能自体も、この時点では実装されていなかった。

## Fix

`src/editor/live-preview.ts` に、リスト項目用の Tab / Shift+Tab を
`Prec.highest` で追加した。

- **Tab**: 直前の兄弟 ListItem の**本文が始まる桁**まで字下げする
  （`- ` なら 2、`1. ` なら 3、`10. ` なら 4）。先頭項目は入れ子にする相手がいないので何もしない
- **Shift+Tab**: 1 つ外側の ListItem の**マークが始まる桁**まで戻す。最上位の項目は何もしない
- リスト項目の行でなければ既定の `indentMore` / `indentLess` に委譲する
- 字下げと同時に、カーソルを含む最も外側のリスト範囲の OrderedList を採番し直す。
  **入れ子のリストは常に 1 から**、最上位のリストは先頭項目の番号を引き継ぐ

字下げと採番は **1 つのトランザクション**にまとめた。採番には字下げ後の構文木が要るため、
`state.update()` で結果の状態を先に作り、そこで番号を計算してから 2 つの ChangeSet を
`compose` して 1 回だけ dispatch している。分けて dispatch すると Ctrl+Z が 2 段になり、
1 回目で「字下げ済み・番号が古い」という**まさにこのバグの状態**が露出してしまう
（実測で確認した）。

文書テキストを書き換えるため、`ensureSyntaxTree` が対象範囲を覆えなかった場合は
採番を行わず字下げだけを適用する。

実キー入力（Playwright）による確認:

| ケース | 結果 |
|--------|------|
| `1./2./3.` の 2 番目で Tab | `1. a` / `   1. b` / `2. c` |
| 入れ子項目で Shift+Tab | `1. a` / `2. b` / `3. c` |
| 2 が入れ子の状態で 3 を Tab | `1. a` / `   1. b` / `   2. c` |
| 3 項目の入れ子の真ん中で Shift+Tab | `1. a` / `   1. b` / `2. c` / `   1. d` |
| 先頭項目を Tab | 変化なし |
| `3.` 始まりのリストの 2 番目で Tab | `3. a` / `   1. b` / `4. c` |
| `1./1./1.` の 2 番目で Tab | `1. a` / `   1. b` / `2. c` |
| 箇条書きの中の番号付き | `- x` / `  1. a` / `     1. b` / `  2. c` |
| 番号付きの中の箇条書き | `1. a` / `   - x` / `     - y` / `2. b`（番号は不変） |
| 箇条書きのみ | `- a` / `  - b` / `- c`（従来どおり） |
| Tab のあと Ctrl+Z 1 回 | 完全に元通り（**1 段で戻る**） |

- **Fix commit**: e75cba6

## Notes

- 検証は開発機の headless Chromium（esbuild で `src/editor` を直接バンドル）。
  Windows / WebView2 は 2026-08-21 にユーザーが確認し合格
- **複数行を選択した状態の Tab は従来どおり**で、採番は行われない。
  選択範囲つきの字下げは既定コマンドに委譲している（spec.md 未対応ケース）
- 同時に、番号付きリストにも箇条書きと同じインデント表示（段ごとの深さ・縦ガイド線・
  折り返し位置）を入れた。こちらは要望であってバグではない
