# BUG-039: タブバーの横スクロールバーが Windows 標準の見た目になる

- **State**: Closed
- **Reported**: 2026-11-23
- **Area**: editor/tabs（`src/styles/app.css` の `.tab-bar`）

## Summary

タブがあふれると出る横スクロールバーが、白いトラック・灰色のつまみ・左右の矢印ボタン付きの Windows 標準のもので、
ダークテーマで目立つ。本文・サイドバーのスクロールバーは Nord 配色に揃っている。タブの下端にも重なって見える。

## Reproduction

1. タブを 14 個ほど開き、タブバーをあふれさせる
2. タブバーの下端に標準のスクロールバーが出る

## Expected

他のスクロール領域と同じ配色・形のスクロールバー。タブのラベルを隠さない細さ。

## Cause

`.tab-bar` に `scrollbar-width: thin` を指定していた。Chromium（WebView2）は標準プロパティの
`scrollbar-width` / `scrollbar-color` が指定された要素では `::-webkit-scrollbar` の装飾を無視し、OS 標準の見た目で描く。
アプリ全体の Nord 配色は `::-webkit-scrollbar` で付けているため、タブバーだけ外れていた。

## Fix

`scrollbar-width` を外し、配色は全体の `::-webkit-scrollbar` に任せた。`.tab-bar::-webkit-scrollbar` で高さを 6px
（つまみの枠 1px）にして、タブのラベルに掛からない細さにした。
