# BUG-038: タブを切り替えて戻ると、スクロール位置が最大 28px ずれる

- **State**: Open
- **Reported**: 2026-11-23
- **Area**: editor/tabs（`src/editor/index.ts` の `saveSession` / `restoreSession`）

## Summary

長いノートをスクロールしてから別のタブへ切り替えて戻ると、同じ行の画面上の位置が最大 28px ずれる。
ずれは積み重ならず、だいたいの位置には戻る（Windows 動作確認 E-06 の観察 1）。

## Reproduction

1. 長文ノートを開き、約 100 行スクロールする
2. 別のタブへ切り替え、元のタブへ戻る
3. 同じ行の画面上の位置が、切り替え前より 16〜28px 上下にずれている

## Expected

離れたときと同じ位置に戻る（spec「編集状態の保持」）。
