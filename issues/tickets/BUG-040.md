# BUG-040: タブが多いと、日本語の名前のタブが「ノート…」ばかりになり見分けられない

- **State**: Fixed
- **Reported**: 2026-11-23
- **Area**: editor/tabs（`src/styles/app.css` の `.tab`）

## Summary

「ノート05」「ノート06」… を 14 個開くと、すべてのタブが「ノート…」と切り詰められ、ツールチップを見ないと区別できない。

## Reproduction

1. 名前の頭が同じノート（ノート01〜ノート14）を 14 個タブで開く
2. すべてのタブが「ノート…」になる（2 個のときは全体が見えていた）

## Expected

タブがあふれたら、各タブは縮まずに横スクロールに任せ、名前が読める幅を保つ。

## Cause

`.tab` が `flex: 0 1 auto; min-width: 80px` で、あふれると 80px まで縮んでいた。余白と × を除くとラベルは約 40px
（日本語 3 文字ほど）しか残らない。

## Fix

`.tab` を `flex: none` にして `min-width` を外した。タブは名前の幅（最大 200px）のまま、あふれた分は横スクロールに任せる。
headless で「ノート01」〜「ノート14」を開き、全ラベルが切り詰めなしで表示されることを確認。
