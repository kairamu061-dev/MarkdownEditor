# BUG-035: 文章の下の行に `-` を入れると、上の文章が見出し 2 になる

- **State**: Closed
- **Reported**: 2026-10-24
- **Area**: editor/core（Markdown パーサの設定 / `@lezer/markdown` の SetextHeading）

## Summary

文章の次の行に `-` を打つと、上の文章が見出し 2 の色・大きさに変わる。
後ろに半角スペースを打って `- ` にしても見出しのまま。

## Reproduction

1. `文章` と入力 → Enter
2. `-` を入力 → `文章` が見出し 2 の表示になる
3. 半角スペースを入力 → まだ見出し 2。`aaa` まで打つとやっと普通の段落 + 箇条書きに戻る

## Expected

文章の下に箇条書きを書き始めただけで、上の文章が見出しに変わらない。

## Cause

**不具合ではなく CommonMark の規則**（setext 見出し）。`文章` の次の行が `-` や `=` だけで
できていれば、上の文章は見出しになる。下線は 1 文字でもよく、後ろの空白も許される。

`- `（空の箇条書き項目）は段落を中断できない規則もあるため、スペースを打っても箇条書きに
ならず、下線の解釈が勝つ。GitHub など他のツールで開いても同じく見出し 2 になる。

## Fix

ユーザーと相談のうえ、**`-` 1 文字だけの下線は見出しにしない**ことにした
（`--` `---` `=` `===` は従来どおり見出し）。

`src/editor/setext.ts` に Lezer のパーサ拡張 `noSingleDashSetext` を追加し、
`src/editor/index.ts` の `markdown()` に渡す。SetextHeading 本体は残し、そのインスタンスを
包んで `-` 1 文字の行だけ素通りさせる（本体を差し替えると段落直下の `---` が水平線に化けるため）。

実測（パーサ単体・headless のエディタ）:

| 原文 | 修正前 | 修正後 |
|------|--------|--------|
| `文章\n-` / `文章\n- ` | 見出し 2 | 段落（`-` は普通の文字） |
| `文章\n- aaa` | 段落 + 箇条書き | 同左 |
| `文章\n--` / `文章\n---` | 見出し 2 | 同左 |
| `文章\n=` / `文章\n===` | 見出し 1 | 同左 |
| `> 文章\n> -` | 見出し 2（引用内） | 段落 |

- **Fix commit**: 48471e0

- 他のツールでは `文章` + `-` の 2 行が見出し 2 に見える。エディタとの食い違いは承知の上
