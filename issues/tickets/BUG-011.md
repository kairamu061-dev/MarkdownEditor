# BUG-011: `>` を消した引用の遅延継続行が引用として振る舞う（斜体が残る・Enter で `> ` が復活）

- **State**: Closed
- **Reported**: 2026-07-26
- **Area**: editor/live-preview・editor/core（@codemirror/lang-markdown）

## Summary

引用行を Enter で継続 → 増えた行の `> ` を Backspace で消して通常文を書くと、その行は見た目上は非引用（左バー・背景・本文色は正しく外れる）だが、CommonMark の**遅延継続（lazy continuation）**でパーサ上はまだ Blockquote 内のため、次の 2 点で引用として振る舞う。

1. **斜体が残る**（軽微）: 本文が italic のまま。
2. **Enter で `> ` が復活する**（体感影響: 中）: その通常行の行末で Enter すると次行に `> ` が自動挿入され引用行になる。

## Reproduction

1. `> quote` と入力 → Enter（`> ` が自動継続。正しい）
2. 継続した 2 行目の `> ` を Backspace で消す → 2 行目を通常行にする
3. 2 行目に通常文（例 `plain line two`）を入力
4. その行末で **Enter** を押す

観察（ディスク実内容）:
```
> quote
plain line two
> ﻿           ← Enter で引用行が自動生成されてしまう
```

また 2 行目は左バー・背景・本文色は通常段落と同じだが、**斜体だけが残る**。

## Expected

`>` を消して見た目が通常段落になった行は、斜体も付かず、Enter しても次行は通常行であるべき（視覚と挙動を一致させる）。

## Cause

引用の装飾・挙動が複数系統に分かれ、判定基準が食い違っているため。

- **左バー・背景・本文色**: `src/editor/live-preview.ts` の行デコレーション。判定基準は `QuoteMark`（行頭の実際の `>` の有無）→ 2 行目は正しく除外できている。
- **斜体**: `src/editor/theme.ts` の `{ tag: t.quote, fontStyle: "italic" }`。これは Lezer の **Blockquote ノード**にかかり、遅延継続で `>` の無い 2 行目も Blockquote に含まれるため斜体が付く。
- **Enter 継続**: `@codemirror/lang-markdown` の `insertNewlineContinueMarkup`（`markdown()` が `Prec.high` で Enter に束ねる）。これも Lezer の Blockquote ノードを見て `> ` を挿入するため、遅延継続行で引用が続く。

いずれも「行頭が実際に `>` か」ではなく「パーサ上 Blockquote 内か」で判定している点が原因。

## Fix

判定基準を QuoteMark（＝行頭の実 `>`）ベースに揃える。

- **斜体**: `theme.ts` の `t.quote` italic を廃し、italic を `live-preview.ts` の `.cm-blockquote`（QuoteMark 基準の行デコレーション）へ移す。→ `>` のある行だけ斜体。
- **Enter 継続**: `live-preview.ts` に `quoteAwareEnter` コマンドを追加し `Prec.highest` で Enter をラップ。カーソル行が行頭 `>`（先頭空白 0〜3 許容）で始まらず、かつパーサ上 Blockquote 内（遅延継続）のときは `insertNewline`（plain 改行）にする。行頭が `>` の行・リスト等は `false` を返して既定の `insertNewlineContinueMarkup` に委ねる。

### 検証（2026-07-26・開発機 headless Chromium）

- 実キー入力で再現テスト（Playwright）:
  - ケースA（`> quote`→Enter→Backspace→`plain line two`→Enter→`X`）: 結果 `"> quote\nplain line two\nX"` = **3 行目に `>` が付かない**（(1') 修正）。
  - ケースB（`> abc`→Enter→`def`）: 結果 `"> abc\n> def"` = **通常の引用継続は維持**（回帰なし）。
- computed `font-style` 確認: `>` 行 = `italic`（`cm-blockquote` あり）、`>` を消した遅延継続行 = `normal`（`cm-blockquote` なし）= (1) 修正。
- ※ Windows 実機での最終確認は次ラウンドで（headless は WebView2 と同じ Chromium 系だが IME/実機は別途）。
- **2026-07-27 の Windows 実機検証（`a8e86b7`）で合格・指摘なし**（斜体なし・Enter で `> ` 復活せず・ディスク一致、本物の引用継続とリスト継続は維持）→ Closed。詳細は `tmp/フィードバック/動作確認結果.md`。
