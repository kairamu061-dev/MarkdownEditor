# BUG-022: ドロップ先ハイライトのちらつき / ステータス通知がツリー再描画で消える

- **State**: Closed
- **Reported**: 2026-08-02
- **Resolved**: 2026-08-06（Windows 実機で動作確認・合格）
- **Area**: file-explorer/tree-view（`src-tauri` ではなく `src/explorer/index.ts`）

## Summary

小さな 2 点（コードレビュー §6）。

1. **dragleave 誤発火**: `makeDropTarget` の `dragleave` が無条件で `drop-target` を外していたため、行内の子要素（`.tree-chevron` / `.tree-label`）にポインタが入った瞬間にドロップ先ハイライトが消える（ちらつく）。ツリー空白部（`treeEl`）側は `e.target` を見ており、同一ファイル内で不整合。
2. **ステータス消失**: `showStatus` が `container` に追加した `.explorer-status` を、`renderTree`（初回）と `renderEmpty` の `container.textContent = ""` が巻き添えで削除し、エラー通知等が意図せず即消える。

## Fix

1. `dragleave` で `row.contains(e.relatedTarget)` を確認し、行内の子へ移っただけなら消さない。
2. `clearContainerKeepStatus()` を追加し、`renderTree`（初回）と `renderEmpty` の全消去を、表示中の `.explorer-status` だけ退避して再付与する形に置き換え。

- **Fix commit**: `118e0a3`

## Notes

- 検証: `tsc`＋`vite` ビルド通過。ちらつき・通知の目視は Windows 実機推奨（軽微）。
- コードレビュー（`tmp/コードレビュー/コードレビュー結果.md` §6）由来。
- **検証（2026-08-06）**: ドラッグ中にフォルダ行の子要素（文字・三角マーク）上へポインタを移してもハイライトが維持されることを確認。同名衝突時のエラー通知も 2.5 秒後まで表示が持続し、移動も行われない。
