# BUG-012: インラインリンク `[text](url)` をクリックしてもノートへ遷移しない

- **State**: Closed
- **Reported**: 2026-07-26
- **Area**: editor/live-preview

## Summary

整形表示された `[text](url)` インラインリンクをクリックしてもノートへ遷移しない（カーソル移動＋ソース表示になるだけ）。表示自体は正常（記法・URL が隠れテキストのみ表示）だが、**クリック用の `data-href` 属性が実は一度も付与されていなかった**。ウィキリンク `[[...]]` は正常に遷移する。

## Reproduction

1. 保管庫に `サブノート.md` などのノートがある状態で、`[サブノートへ](サブノート.md)` を含むノートを開く
2. カーソルをリンクの外に出す（テキストのみ表示になる）
3. 「サブノートへ」をクリック

観察: 遷移せず、カーソルが入ってソース表示に戻るだけ。

## Expected

リンクテキストのクリックで `サブノート.md` が開く（ウィキリンクと同等）。

## Cause

`src/editor/live-preview.ts` の Link 処理が、リンクテキストの範囲を **`LinkText` という構文ノードから取得**しようとしていた。しかし `@lezer/markdown` の `Link` ノードに **`LinkText` ノードは存在しない**。子ノードは `LinkMark`（`[` `]` `(` `)`）と `URL` のみで、テキストは最初の `[` と `]` の LinkMark に挟まれた「隙間」でしかない。

そのため `ltFrom/ltTo` は常に `-1` のままで、`data-href` を持つ `cm-md-link` マークが**一度も追加されず**、`mousedown` ハンドラの `closest("[data-href]")` が常に空振りしていた。表示（記法・URL の隠蔽）は機能していたため見た目は正常で、遷移だけが無言で失敗していた。

※ 2026-07-20 の E-08 は「合格」と記録されていたが、自動操作がカーソル移動を遷移と誤認した偽陽性だったと判断（本ラウンドで 5 回の合成クリックすべて非遷移、ユーザー実機でも非遷移を確認）。

パーサ確認（`[text](note.md)`）:
```
Link [0,15]
  LinkMark [0,1] "["
  LinkMark [5,6] "]"
  LinkMark [6,7] "("
  URL      [7,14] "note.md"
  LinkMark [14,15] ")"
```

## Fix

リンクテキスト範囲を LinkMark から導出するよう変更。`Link` の子から `LinkMark` を文書順に集めると `[ '[', ']', '(', ')' ]` になるので、テキスト＝`marks[0].to`〜`marks[1].from`。ここに `data-href` 付き `cm-md-link` マークを付与し、`[` と `](URL)` を隠す。

- **Fix commit**: `93d78f5`
