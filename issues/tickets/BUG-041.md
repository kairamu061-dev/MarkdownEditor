# BUG-041: 1 文字の名前のタブは、中央をクリックすると切り替わらずに閉じる

- **State**: Closed
- **Reported**: 2026-11-24
- **Area**: editor/tabs（`src/styles/app.css` の `.tab`）

## Summary

名前が 1 文字のノート（例: `B`）のタブは幅が約 50px しかなく、タブの中央をクリックすると × ボタンに当たって、
切り替えのつもりがタブが閉じる。BUG-040 の修正（`fe7f76b`）で最小幅を外したことで入った退行。

## Reproduction

1. `A`・`B` のような 1 文字の名前のノートを 2 つタブで開く
2. 裏のタブの中央付近をクリックする
3. 切り替わらず、そのタブが閉じる

## Expected

タブのどこをクリックしても（× 以外）切り替わる。× は右端にあり、狙わないと押さない。

## Cause

`fe7f76b` で `.tab` を `flex: none` にしたとき、`min-width: 80px` も外した。1 文字のタブは
左余白 12px + ラベル約 8px + 間隔 4px + × 18px + 右余白 6px ≒ 48px となり、中央（24px 付近）が × の左端に重なる。
BUG-040 の原因は「縮むこと」（`flex-shrink`）で、最小幅は外す必要がなかった。

headless で BUG-038 の再現を自動化していた際、`.tab` の中央クリックで B が閉じて気づいた。
2026-11-24 の Windows 確認で「手順の誤りで B のタブを閉じてしまった」とあるのも、同じ原因の可能性が高い。

## Fix

`.tab` に `min-width: 80px` を戻した（`flex: none` はそのままなので、BUG-040 の「縮んで読めない」は再発しない）。
ラベルが `flex: 1` で余りを取るため、× は常に右端に寄る。

- **Fix commit**: 9d06686
