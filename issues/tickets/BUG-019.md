# BUG-019: インラインリンクだけサブフォルダ指定が効かない

- **State**: Closed
- **Reported**: 2026-08-02
- **Resolved**: 2026-08-06（Windows 実機で動作確認・合格）
- **Area**: editor/live-preview（`main.ts` のリンクコールバック）

## Summary

`[text](sub/note.md)` のようにフォルダ付きで書いても、インラインリンクはクリック時にフォルダを捨ててファイル名だけで解決していた。ウィキリンク `[[sub/note]]` は BUG-015 で `node.path` 照合に対応済みなのに、**同じリゾルバ（`openNoteByName`）に対して 2 記法が別挙動**になっていた（同名ノートが別階層にあるとき、意図と違うほうが開く）。

## Cause

`main.ts` の `livePreview` コールバックが `const base = name.split(/[\\/]/).pop()` でフォルダを捨てて `openNoteByName(base)` を呼んでいた（コードレビュー §3）。ウィキリンクは `name` をそのまま渡している。

## Fix

`base` を経由せず、先頭 `./` だけ除いた `name`（フォルダ付き）をそのまま `openNoteByName` に渡す。`openNoteByName` は BUG-015 で `.md` 補完＋`node.path` 完全一致に対応済みなので、ウィキリンクと同一精度になる。

- **Fix commit**: `118e0a3`
